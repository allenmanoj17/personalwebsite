# Allen Manoj — Personal Portfolio

Welcome to my personal website and portfolio! I’m **Allen Manoj**, a data-driven problem solver, passionate about turning data into insights, beautiful visuals, and meaningful products.


## 🚀 Features

- Built with [Next.js](https://nextjs.org/) for fast, modern web performance
- Animated **Neural Network Visualization** using [Three.js](https://threejs.org/)
- Responsive design for mobile and desktop
- Dynamic project showcase
- Smooth animations with [Framer Motion](https://www.framer.com/motion/)
- Deployed on [Vercel](https://vercel.com/)

## 📝 How to Run Locally

1. **Clone the repository**

    ```bash
    git clone https://github.com/allenmanoj17/personalwebsite.git
    cd personalwebsite
    ```

2. **Install dependencies**

    ```bash
    npm install
    ```

3. **Start the development server**

    ```bash
    npm run dev
    ```

4. Open your browser at [http://localhost:3000](http://localhost:3000)
